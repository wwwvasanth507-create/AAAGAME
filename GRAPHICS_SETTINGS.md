# GRAPHICS SETTINGS SPECIFICATION — HERO OF ETERNIA (PROMPT 23)

## System Overview
`GraphicsSaveData.cs` encapsulates post-processing toggles, shadow quality, render scale, and preset selections. Integrated into `SaveProfile` Version 18.

## Save V18 Schema

```json
{
  "QualityPreset": "High",
  "BloomEnabled": true,
  "AmbientOcclusionEnabled": true,
  "DepthOfFieldEnabled": false,
  "MotionBlurEnabled": false,
  "VignetteEnabled": true,
  "ShadowQuality": "Medium",
  "TargetRenderScale": 1.0,
  "SaveVersion": 18
}
```
