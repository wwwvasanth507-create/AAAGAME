# CHARACTER ANIMATION PROFILES — HERO OF ETERNIA (PROMPT 22)

## Overview
`CharacterAnimationProfile.cs` decouples state logic from raw clip names, enabling non-programmers and designers to bind animation clips to character archetypes without writing code.

## Archetypes
* **Player**: Standard hero movement, dodging, attacks, and interactions.
* **NPC / Merchant**: Gentle idle, greeting gestures, conversation loops.
* **Guard / Bandit**: Alert stance, weapon brandishing, patrol walk.
* **Monster / Boss**: Aggressive idle, heavy attacks, stagger reactions, defeat collapses.
* **Animal / Creature**: Quadruped locomotion, grazing, roaring.
