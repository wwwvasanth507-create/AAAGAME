# HERO OF ETERNIA — GLOBAL PROJECT RULES

These rules are permanent and apply to every prompt from Prompt 1 through Prompt 150 unless a future prompt explicitly replaces them.

## GLOBAL AI-FIRST CONTENT CREATION POLICY
Hero of Eternia must be developed using an AI-first production pipeline.
Whenever a phase requires any asset, content, documentation, or production material, generate or prepare it automatically as part of that phase.
Never leave placeholders like:
* "Create later"
* "Add assets later"
* "Use temporary artwork"
* "Artist will create later"
Instead, create the production-ready asset or the complete AI generation pipeline for that asset.

## AI ASSET GENERATION RULE
Whenever any of the following are required, automatically generate them using AI workflows.
This includes but is not limited to:
* Character concept art, NPC portraits, Enemy/Boss concepts, Weapons, Armor, Shields, Accessories
* Icons, Skill icons, Inventory icons, UI illustrations
* Loading screens, Splash screens, Promotional artwork, Story/Quest illustrations
* Maps, Minimap graphics, World/Region/Dungeon maps
* Environmental concepts, Buildings, Cities, Villages, Castles, Trees, Rocks, Vegetation, Terrain textures
* Skyboxes, Clouds, Weather effects, Water materials, Particle textures, Backgrounds, Props, Furniture, Collectibles, Consumables, Crafting materials
* 3D characters, NPCs, enemies, bosses, creatures, weapons, armor, props, building/environment assets
* Animations, Rigging, Blend shapes, Materials, PBR textures, UV layouts, LOD models, Collision meshes
* Audio concepts, Music prompts, Ambient sounds, Sound effects, Voice generation specs, Lip-sync metadata

Everything required for the game should be produced through an AI-assisted workflow unless external assets are explicitly requested.

## AI PROMPT GENERATION TEMPLATE
For every generated asset automatically provide:
* Asset name
* Purpose
* Style & Art direction
* Technical specifications
* AI generation prompt
* Negative prompt (when appropriate)
* Image/Texture resolution
* Polygon budget (for 3D)
* Animation & Material requirements
* Naming conventions & Export format
* Folder location
* Version metadata

## 3D MODEL RULES
Whenever a 3D model is required automatically generate production specifications for:
* High-poly model
* Game-ready low-poly model
* Retopology, UV mapping, PBR textures (Normal, AO, Metallic, Roughness, Emission)
* Rigging, Animations, LOD0/LOD1/LOD2 models
* Collision meshes, Prefab setup, Optimization (Android performance requirements)

## IMAGE RULES
Whenever artwork is required automatically generate:
* Concept art, Final illustration, Transparent PNG version, Icon version, UI version, Thumbnail, Loading screen version, Marketing version, High-resolution archive

## AUDIO RULES
Whenever audio is required automatically generate:
* Music generation prompt, Sound effect prompt, Ambient sound prompt, Voice description, Emotional tone, Loop settings, Export specifications

## AUTOMATIC PIPELINE CONTENTS
Every phase should automatically include:
1. Code
2. Documentation
3. Configuration
4. Tests
5. AI asset specifications
6. AI image prompts
7. AI 3D model prompts
8. AI texture prompts
9. AI animation prompts
10. AI audio prompts
11. Optimization
12. Validation
13. Folder organization
14. Asset manifests
15. Production checklists

## CONSISTENCY RULE
All generated assets must remain consistent across the entire project. Maintain visual identity, color palette, character proportions, architecture style, lighting style, material language, UI language, typography, animation quality, and lore consistency.

## OUTPUT REQUIREMENTS
Every future prompt (1–150) must automatically include an **AI Asset Production** section containing:
* Assets introduced in that phase
* Image, 3D model, texture, animation, and audio generation prompts
* Technical specifications
* Folder structure & File naming
* Asset manifest updates
* Validation report & Optimization notes
